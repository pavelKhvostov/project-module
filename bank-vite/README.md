NeoBank

📌 Description

NeoBank App is a responsive web application built with Vite and React. The core functionality includes currency conversion using an external API. The project is designed with scalability in mind — users will eventually be able to create and customize their own virtual bank card.

# Install dependencies

npm install

# Run the development server

npm run dev

# Build for production

npm run build
